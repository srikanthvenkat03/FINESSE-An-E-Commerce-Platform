# 🛍️ Finesse - Trendy Clothing Store

**Finesse** is a full-stack clothing e-commerce web application that allows users to explore and shop trendy oversized t-shirts from popular fandoms like Game of Thrones, Jujutsu Kaisen, and Stranger Things.

---

## ✨ Features

* **User Authentication** – Signup and login functionality using Express and MongoDB.  
* **Responsive UI** – Clean and modern layout built with React.  
* **Landing Page** – Rotating banners, top categories, product listings.  
* **Add to Cart (UI)** – Buttons available for cart interaction.  
* **Background Styling** – Beautiful UI with background images and blur effects.  

---

## 🚀 Tech Stack

* **Frontend:** React, React Router, CSS  
* **Backend:** Node.js, Express  
* **Database:** MongoDB  
* **Tools:** Git, GitHub, GitHub Desktop, VS Code
